1. SCAMPER Framework (Advanced)

SCAMPER is a structured innovation method used to generate ideas by applying seven lenses:

  • Substitute – Replace tools, people, or steps
  • Combine – Merge processes or responsibilities
  • Adapt – Borrow ideas from other domains
  • Modify – Change scale, structure, or timing
  • Put to another use – Reuse assets in different ways
  • Eliminate – Remove unnecessary complexity
  • Rearrange – Change order or workflow

Execution Template

  1. Define the problem clearly
  2. Apply all SCAMPER dimensions
  3. Generate at least 3 ideas per dimension
  4. Select high-potential ideas
  5. Define implementation steps

2. Lateral Thinking

Lateral thinking focuses on breaking conventional patterns and exploring unconventional approaches. It challenges assumptions and introduces unexpected perspectives.

  • Question existing assumptions
  • Introduce randomness or outside ideas
  • Reframe the problem instead of solving it directly

3. Analogical Thinking

Analogical thinking involves solving problems by comparing them to solutions used in other industries.

Examples:

  • How would Netflix improve this experience?
  • How would Amazon optimize this workflow?
  • How would a startup approach this problem?

4. Structured Brainstorming

Effective brainstorming follows these principles:

  • Focus on quantity first
  • Avoid criticism during ideation
  • Build on existing ideas
  • Cluster ideas after generation

5. Root Cause Analysis (5 Whys)

The 5 Whys technique identifies root causes by repeatedly asking "Why?" to move beyond symptoms and uncover the real problem.

  1. Define the problem
  2. Ask why it happens
  3. Repeat up to 5 times
  4. Identify root cause
  5. Design targeted solutions

6. Impact vs Effort Matrix

  • High Impact / Low Effort → Quick Wins ✅
  • High Impact / High Effort → Strategic Initiatives 🚀
  • Low Impact / Low Effort → Optional
  • Low Impact / High Effort → Avoid ❌

This framework helps prioritize ideas effectively and focus on high-value outcomes.
